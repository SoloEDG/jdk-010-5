# LUMEN 光学实验室

二维几何光学实验台，带有可回放的**参数时间轴**：为器件位置、角度、焦距与
光源功率设置关键帧，播放时重新计算光路与接收屏信号。

## 运行

```bash
npm install
npm run dev        # http://localhost:5173
npm run typecheck
npm test           # 时间轴与光学单元测试
npm run build
```

Docker：`docker compose up --build`，访问 http://localhost:18110 。

## 参数时间轴

- 选中器件后，时间轴会显示该器件可动画的通道：X/Y 位置、旋转角度、焦距
  （透镜）、光源功率（光源）。
- 在刻度上拖动播放头，输入数值后点「+ 关键帧」；拖动关键帧改变时间（方向键
  微调 10ms / Shift 100ms，`Delete` 删除，双击也删除）。
- 未设置关键帧的参数沿用布局值；关键帧按器件 `id` 绑定。
- 首次播放前会检查角度歧义；播放中可继续编辑关键帧，停止后回到编辑态。

未选中器件时，时间轴显示「轨道总览」，列出所有带关键帧的器件及分布，
点击行即可进入该器件的通道编辑。

### 时间定义

`sampleTimes(window, step)` 是唯一的时间定义：返回闭区间 `[start, end]`
内步长为 `step` 的全部整数毫秒，并在终点不在网格上时追加终点。

逐帧测量、播放监测、严谨校验与 CSV 导出全部调用同一函数；`nextSampleTime`
/ `sampleTimesBetween` 只是它的分段形式，拼起来与一次性采样逐点一致（有测试）。

### 两种精度的协作

| | 流畅预览 | 严谨校验 |
|---|---|---|
| 视觉时间 | wall-clock，整数毫秒 | 只落在采样网格上 |
| 视觉重算 | 最少间隔 50ms，可合并 | 每个显示帧都重算 |
| 掉帧影响 | 只影响画面，计数可见 | 不影响时间推进 |

无论选哪种精度，播放监测都会把每次刷新跨越的**所有**采样网格点逐点追迹。
因此一次卡顿不会跳过 20ms 的短暂失败；`监测 x/y` 与严谨校验的采样点始终
一一对应。

跳转（拖动播放位置、点击失败区间、逐点步进）会跳过中间的采样点，监测
覆盖因此被显式重建：显示为「覆盖不连续 / 正在重新累计」，不会伪造一个
「整窗达标」的结论。只有从时间窗起点连续播放到终点，且每个采样点都达标，
才判定持续达标。

### 角度的 ±180° 接缝

角度关键帧区间跨越 ±180° 时，最短路径与用户意图可能相反，因此播放前必须
选择「逆时针 / 顺时针」。选择结果写回区间左关键帧的 `direction`，可撤销；
未选择时按最短路径运行并明确标记为歧义（严谨校验不通过）。

### 焦距经过 0

薄透镜焦距 0 是退化情形。插值结果 `|f| < 1mm` 时钳制到 `±1mm`，符号取插值
方向一侧；每个被钳制的采样点都会在 `issues` 中标记。不会出现 `NaN`、无限
焦距或静默跳过。

### 器件增删

删除器件会**同时**删除其全部关键帧轨道，并作为单个撤销步骤。时间轴中若因
导入等原因残留了指向已删除器件的轨道，轨道会保留但明确报告「不会生效」，
绝不复活器件。

### 预览与布局

播放只产生**派生**的预览文档（`documentAt`），从不写回布局：

- 画布与接收屏面板显示预览帧，并标注「预览帧 · 布局未修改」；
- 参数面板始终显示布局值，播放中锁定编辑；
- 停止回到 0ms 与编辑态；暂停保留播放位置但布局不变。

### 时间窗「持续达标」

任务面板与校验面板显示当前时间窗。只有窗口内**每个**采样点都达标才算
通过；任何一段失败都会列出起止时间，点击可把播放头定位到该采样点。
面板中的采样数、失败段、最差能量比/RMS 与导出的 CSV 完全同源。

CSV 导出包含采样时间定义注释与逐点结果。若要复现整段动画，需要同时
保留关键帧：`toCsv(check, meta, "both")` 会把关键帧与采样表写进同一份
CSV（界面按钮导出采样表）。
